HenriWorks · documentação animada · pacote para SharePoint Online

Conteúdo: index.aspx, app.js, style.css, vendor/motion-lite.js (MIT, sem dependência).
Nenhum script inline, nenhum recurso externo: compatível com a CSP de scripts do SharePoint (2026).
Movimento contínuo é CSS e SMIL (sem script); com JavaScript bloqueado a página continua completa.

Deploy
1. Confirme com o admin do site que custom script está liberado (ou peça a janela de 24 h).
   Não peça para liberar custom script no tenant inteiro.
2. Faça upload como Owner do site, pelo botão Upload da biblioteca, mantendo a pasta vendor/ junto.
3. Abra index.aspx numa janela anônima (InPrivate).
4. F12 → Console: procure "violates ... Content Security Policy". Se os .js da biblioteca forem
   bloqueados, peça ao admin para incluir a URL da biblioteca em Trusted script sources.
5. Teste com ?csp=enforce na URL se o tenant ainda estiver em modo de relatório.

Sintomas
- Clicar baixa o arquivo: .aspx marcado como NoExecute. Reenvie como Owner durante a janela.
- Abre sem estilo: style.css não foi enviado ou a estrutura de pastas mudou.
- Abre sem animação de clique (chat, terminal, fatias): CSP bloqueou os scripts (passo 4).

Alternativa mais robusta, se a página for recorrente: host interno + web part Embed, ou web part SPFx.
